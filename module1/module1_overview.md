# Module 1: Computational Thinking and Your First Programs

## Module overview

Welcome to CIS 110. Before we write any code, we learn to think about problems,
and this module sets the habit the rest of the quarter is built on: understand
the problem, plan the solution, then write the code. You will write every line
in this module yourself, without AI assistance. That constraint is deliberate.
Later in the course you will direct AI tools to produce code for you, and the
only thing that will make that useful rather than dangerous is your own ability
to tell whether what comes back is right. That ability starts here, with small
programs you understand completely.

## Module objectives

By the end of this module, you will be able to:

1. Describe the stages of computational problem solving: decomposition,
   pattern recognition, abstraction, and algorithm design.
2. Set up and use a Python development environment to write, run, and save
   programs.
3. Use variables, expressions, and the core data types (`int`, `float`, `str`,
   `bool`) correctly, including type conversion.
4. Read user input and produce clearly formatted output.
5. Explain the course's AI-use policy and distinguish assisted from unassisted
   work.

## Readings and resources

**Required**

- **Severance, C. R. *Python for Everybody: Exploring Data in Python 3*,
  Chapters 1–2** (open access, [py4e.com](https://www.py4e.com/book)).
  These two chapters give you the first steps in writing Python. Chapter 1
  explains what a program is and why learning to write one is worth it;
  Chapter 2 introduces variables, expressions and statements — the exact
  building blocks you use in Lab 1.
- **Python Software Foundation, *The Python Tutorial*, sections 1–3**
  ([docs.python.org/3/tutorial](https://docs.python.org/3/tutorial/)).
  The official introduction, written by the people who make Python. Sections 1–3
  show you how to run Python and use it as a calculator with numbers and text.
  We read primary documentation from week one because later, when an AI tells
  you something about Python, this is where you check whether it is true.
- **[CIS 110 AI-Use Policy](../welcome/06_ai_use_policy.md)** (course page).
  Explains the four permission levels you will see on every assignment. Lab 1 is
  *Unassisted*.

**Optional**

- **Sweigart, A. *Automate the Boring Stuff with Python*, Chapter 1**
  (open access, [automatetheboringstuff.com](https://automatetheboringstuff.com/)).
  The same basics as Severance, explained a different way with practical
  examples. Read it if a concept from the required reading has not clicked yet.
